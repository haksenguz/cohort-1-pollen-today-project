# docs/headache/

What hurt us, and whether we fixed it. One problem per file. Changes when we hit
or resolve a problem. This is how a mistake gets made once, not twice.

Frontmatter, same staleness mechanism as `docs/research/`:

```markdown
---
status: open           # open | resolved
owner: Ismoiljon
review-by: 2026-10-08
---
```

Write one when a bug, a wrong agent diagnosis, or a bad assumption costs real
time. Record what happened, the root cause, and the fix, so the next person (or
agent) checks here before repeating it.
