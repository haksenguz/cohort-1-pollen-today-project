# research/

What is true about the world, and how we know. One claim per file. Changes when
reality changes or we measure again.

Every file carries frontmatter so staleness is a date check, not a judgement:

```markdown
---
status: current        # current | stale | superseded
owner: Ismoiljon
review-by: 2026-12-08
---
```

Examples that belong here: which pollen/AQI/weather API actually covers Korea and
its rate limits; what PM2.5 thresholds map to which risk band; validated symptom
red-flag criteria and their source.
